A one-line software patch note for a bug in real life: walking into a room deletes the reason you went in, and the official workaround is standing in the doorway until your brain reboots.

## How to run

Requires Node 22 or later. From the repository root:

```sh
node main.ts
```

This writes the single-line entry to `/output/entry.txt` (1–160 characters, one line, no trailing newline). The program throws if the line is outside 1–160 characters or contains a newline.

## Entry

> v4.2.0: fixed a bug where walking into a room deleted the reason you came in. Workaround: stand in the doorway until your brain reboots.
